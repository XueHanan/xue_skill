# 可选终检微调

表达已经自然时直接交付，不固定增加第二、第三轮。若确有残留表达问题，最多做一次保守微调；不要求调用额外插件。

使用外部润色工具前发现实际工具并读取当前参数和返回结构，不假定 whale_polish 或 T1/L2 在所有环境存在。只传本任务需要处理的改后普通叙述，不传原文对照、表格、公式、代码和引用列表。工具不可用时跳过，不中断交付。

含 EQ/OBJ 标记或冻结内容的段落不交给外部工具。普通叙述中的数字、术语和引用也必须保护；工具的 changes 描述只作线索，不能代替比对与语义复核。

微调前保存 comparison.md 的快照；失败、空结果、语言变化或内容被改动时直接回退对应段，不重复调用工具修复第一次结果。

微调后重新完成语义复核并运行整个统一验证：

```text
PYTHON SCRIPTS/validate.py FINAL.md TASK --review NEW_REVIEW.json --before-final BEFORE.md --ratio 0.15
```

这里的 ±15% 指这一次终检前后中文字符与英文词的统计单位数变化，不是物理单位数量，也不是原稿到全部改写的压缩比例。仅传 --before-final 时启用，实际超限则失败并回退。正文没有变化时无需更新复核。

验证器重新合成正文、计算统计并生成附录；只交付当前报告指向的结果，不能沿用微调前的通过状态。
